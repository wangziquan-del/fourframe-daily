# 四框架每日选品

大宗商品期货全品种四框架技术分析 · 三级别(15分钟/60分钟/日线) · GitHub Pages 公网

## 访问
https://wangziquan-del.github.io/fourframe-daily/

## 内容
- **四框架**：缠论结构 + MACD/RSI + 江恩区间位 + 量价
- **三级别**：15分钟 / 60分钟 / 日线，每级别独立评分分类
- **四分类**：好(技术最强) / 坏(空头最扎实) / 中性待突破 / 性价比(低位金叉)，各取3
- **每品种**：四框架评述表 + 入场/止损/目标

## 自动更新（北京时间）
| 时点 | 说明 |
|---|---|
| 09:05 | 日盘开盘后 |
| 11:25 | 上午盘尾 |
| 14:00 | 下午盘中 |
| 21:30 | 夜盘开盘后 |

数据源：日线=知几(SMM/Mysteel镜像)，15/60分钟=新浪期货实时。
生成：`gen_fourframe_web.py`，GitHub Actions 定时触发构建并部署。
